## 📌 Sobre o Projeto

O **RankLab** tem como objetivo `Fazer a Implementação do Bubble Sort, Selection Sort e Insertion Sort`.

Este repositório reúne os artefatos produzidos ao longo das etapas de modelagem, tais como:

* Levantamento de requisitos e regras de negócio
* Modelo Conceitual (DER / MER)
* Modelo Lógico (entidades, atributos, chaves primárias/estrangeiras e cardinalidades)
* Modelo Físico / Scripts SQL (criação de tabelas, restrições e consultas)
